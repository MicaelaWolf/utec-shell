# Archivos de inicialización, variables y expansiones

0-alias: Crea un alias de nombre: "ls" y valor: "rm -f *".

1-hello_you: Imprime "hola user", donde user es el usuario actual de Linux.

2-path: Añade /action a la PATH. /action debe ser el último directorio que el shell revisa al buscar un programa.

3-paths: Cuenta el número de directorios en el PATH.

4-global_variables: Lista las variables de entorno.

5-local_variables: Lista todas las variables locales y de entorno, y las funciones.

6-create_local_variable: Crea una nueva variable local de nombre: "BEST" y valor: "School".

7-create_global_variable: Crea una nueva variable global igual a la anterior.

8-true_knowledge: Imprime el resultado de la suma de 128 con el valor almacenado en la variable de entorno TRUEKNOWLEDGE, seguido de una nueva línea.

9-divide_and_rule: Imprime el resultado de POWER dividido por DIVIDE, seguido de una nueva línea.

10-love_exponent_breath: Muestra el resultado de BREATH elevado a la potencia LOVE.

11-binary_to_decimal: Convierte un número de base 2 a base 10 almacenado en la variable de entorno BINARY.

12-combinations: Imprime todas las combinaciones posibles de dos letras minúsculas, excepto "oo", ordenados alfabéticamente.

13-print_float: Imprime un número con dos decimales almacenado en la variable de entorno NUM.

14-decimal_to_hexadecimal: Convierte un número de base 10 a base 16 almacenado en la variable de entorno DECIMAL.

15-rot13: Codifica y decodifica texto usando el cifrado rot13. Asume ASCII.

16-odd: Imprime cada otra línea de la entrada, comenzando con la primera línea.

17-water_and_stir: Suma los dos números almacenados en las variables de entorno WATER y STIR e imprima el resultado. WATER está en base "water". STIR está en base "stir". El resultado debe estar en base "bestchol".
